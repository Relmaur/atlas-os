# Advanced Materials Economy

**Advanced Materials** is an [[Economy]] type.

## Summary

Advanced Materials [[Star system|systems]] are represented by a double helix symbol and are seen as purple [[star|stars]] when using the [[Economy Scanner|economy filter]] in the [[Galactic Map]].

Advanced Materials systems supply [[tradeable|tradeables]] to [[Scientific Economy|Scientific]] systems and buy from [[Trading Economy|Trading]] systems.

## Names

Advanced Materials systems can have one of the following names:
- Material Fusion
- Metal Processing
- Ore Processing
- Alchemical

## Tradeables

The following tradeables, from lowest to highest value, are produced by Advanced Materials systems:
- [[Nanotube Crate]] (Base Value 1000u)
- [[Self-Repairing Heridium]] (Base Value 6200u)
- [[Optical Solvent]] (Base Value 16000u)
- [[Five Dimensional Torus]] (Base Value 31500u)
- [[Superconducting Fibre]] (Base Value 53000u)

The following tradeables, from lowest to highest value, have high demand in Advanced Materials systems:
- [[Decrypted User Data]] (Base Sale Price 350u)
- [[Star Silk]] (Base Sale Price 6000u)
- [[Comet Droplets]] (Base Sale Price 12500u)
- [[Ion Sphere]] (Base Sale Price 28000u)
- [[Teleport Coordinators]] (Base Sale Price 50000u)
