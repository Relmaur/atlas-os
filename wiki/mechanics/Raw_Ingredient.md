# Raw Ingredient

**Raw Ingredient** is a type of consumable.

## Summary

**Raw Ingredient** is a type of [[consumable]], and the base materials for [[cooking]] into [[Edible Product|Edible Products]].

## Use

- Can be used as [[bait]] for [[fishing]].
- Can be consumed for various [[Exosuit]] bonuses.
- Can be [[Cooking|cooked]] into [[Edible Product|Edible Products]].
- Can be presented to [[Iteration: Cronus]] in the [[Space Anomaly]] for [[Nanite Cluster|nanite]] Nanites rewards.
- Can be fed to [[Organic Frigates]] to [[Organic Frigates|redistribute]] their existing Combat/Exploration/Industry/Trade values.
