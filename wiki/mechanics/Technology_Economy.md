# Technology Economy

**Technology** is an [[Economy]] type.

## Summary

Technology [[Star system|systems]] are represented by a nanites symbol and are seen as light blue [[star|stars]] when using the [[Economy Scanner|economy filter]] in the [[Galactic Map]].

Technology systems supply [[tradeable|tradeables]] to [[Power Generation Economy|Power Generation]] systems and buy from [[Manufacturing Economy|Manufacturing]] systems.

## Names

Technology systems can have one of the following names:
- Engineering
- High Tech
- Nano-Construction
- Technology

## Tradeables

The following tradeables, from lowest to highest value, are produced by Technology systems:
- [[Decommissioned Circuit Board]]  (Base value 1000u)
- [[Welding Soap]] (Base value 6000u)
- [[Ion Capacitor]] (Base value 15000u)
- [[Autonomous Positioning Unit]]  (Base value 30000u)
- [[Quantum Accelerator]]  (Base value 50000u)

The following tradeables, from lowest to highest value, have high demand in Technology systems:
- [[Enormous Metal Cog]] (Base sale price 550u)
- [[Non-Stick Piston]] (Base sale price 4100u)
- [[Six-Pronged Mesh Decoupler]] (Base sale price 13000u)
- [[Holographic Crankshaft]] (Base sale price 30000u)
- [[High Capacity Vector Compressor]] (Base sale price 50000u)
